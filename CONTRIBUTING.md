# Contributing

**This repository does not accept pull requests.** It is a read-only mirror: every file
here is generated by an export job from a private monorepo, so a merged change would be
silently reverted by the next sync. Pull requests opened here will be closed with a link
to this file — that is not a judgement of the change, it is the only honest answer.

**Issues are open, and they are the point.** Bug reports, unexpected behaviour, unclear
documentation, a missing capability — file them here. They are read, and fixes land
upstream and arrive in the next release.

When reporting a bug, the version and the host matter more than anything else:

```
package version, and the version of the agent or editor you are running it in
what you expected, and what happened instead
the smallest sequence that reproduces it
```

Please leave out credentials, internal hostnames, and customer data — an issue is public
the moment it is filed.
